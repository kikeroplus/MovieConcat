`CLAUDE.md` をプロジェクト直下、この文書を `docs/PLAN.md` に置いて進める。
各フェーズの終わりに「完了条件」を自分の目で確認し、`git status` → `git diff` → コミット、の順で区切る。
テスト用に、コピーした動画だけを入れた検証フォルダを用意しておく（本番フォルダでは試さない）。

## Phase 1: 土台（一覧表示・再生・評価の読み書き確認）

**作業**
- `core/probe.py`（VideoInfo、回転考慮、creation_time、キャッシュ）
- `core/worker.py`（QThread 基盤）
- `core/rating.py`（読み書き・値変換）
- メインウィンドウの 3 ペイン骨格、フォルダ選択、未分類／グループフォルダのツリー表示
- 動画テーブル（チェック列以外の表示列）、行選択で mpv 再生

**完了条件**
- 日本語・空白入りパスのフォルダで一覧が出て、選んだ動画が再生できる
- MP4 / M4V / WMV それぞれで、コード上から評価を書き込み、エクスプローラーの★に反映される
- 再生中ファイルへの書き込みが「アンロード → 書き込み」で成功する

---

## Phase 2: 評価操作・フィルタ・選択

**作業**
- キー操作（0〜5、Space、←→、↑↓）
- 1 本評価時の自動送り、複数対象時の一括評価
- フィルタ（すべて / 評価済み / ★N以上 / 未評価 / 除外中）
- チェック列と選択ボタン（すべて / 解除 / 反転 / 表示中のみ）
- `core/state.py` と除外フラグ（E キー）、状態列の表示

**完了条件**
- 数字キーだけで次々に評価していける
- 20 本を「表示中のみ全選択 → 1」で一括評価できる
- 除外したファイルがアプリ再起動後も除外中のまま

---

## Phase 3: フォルダ分け

**作業**
- `core/grouping.py`（除外中は移動しない、WMV は `_wmv` 付き、同名スキップ）
- 確認ダイアログ（グループごとの本数）
- history への記録と Ctrl+Z による元に戻す（フォルダ分け分のみ）
- 移動に伴う state のパス更新

**完了条件**
- 解像度混在・WMV 混在・縦動画（回転あり）・除外中を含む検証フォルダで、期待どおりに分かれる
- 元に戻すで完全に元の配置に戻る

---

## Phase 4: 結合

**作業**
- `core/concat.py`：互換性判定（A / B / C）、concat demuxer、音声正規化、再エンコード
- 結合順（ファイル名の自然順 / 作成日時 / 手動）、手動モードでのドラッグ並べ替えと manual_order 保存
- 実行前確認ダイアログ（本数・合計時間・判定）、進捗、キャンセル、一時ファイル掃除
- `_output` への上書き出力、「出力動画」ノードの更新

**実装順のおすすめ**
1. 判定 A だけで一通り動かす
2. 判定 B（音声正規化）を追加
3. 判定 C（再エンコード）を追加
4. キャンセルと後片付け

**完了条件**
- 同一形式のグループが無劣化で結合され、つなぎ目で音ズレしない
- 音声形式が混在するグループ、音声なしが混ざるグループが確認なしで結合される
- 映像不一致のグループで警告が出て、「しない」を選ぶとスキップされる
- 途中キャンセルで一時ファイルと作りかけの出力が残らない
- 出力を再生中に再実行しても上書きできる

---

## Phase 5: ファイル操作

**作業**
- ごみ箱へ（確認あり）
- 別フォルダへまとめる（移動 / コピー選択、同名スキップ）
- 元に戻すの対象を移動・コピーにも拡張
- すべての操作前のプレイヤー停止、state のパス更新

**完了条件**
- 再生中のファイルを含めても削除・移動が失敗しない
- 移動 → 元に戻す、で評価も除外フラグも維持されている

**作業**
- 設定の保存・復元（最後のフォルダ、結合順、エンコーダ、ウィンドウ配置）

**完了条件**: 数百本規模のフォルダで、スキャン → 評価 → フォルダ分け → 結合 → 整理を一通り通せる。
